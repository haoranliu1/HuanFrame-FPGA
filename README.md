## 目录

image_A：960×720后备帧、640×480输出，六图、缩放拖动、分屏、转场、BGM及网络字幕。

video_B：320×240约14fps源、24kHz PCM、四帧水库、三种音柱。

touch：无人机六图可编辑HMI、页面JSON、配对清单和预览资源；新版原生生产TFT待厂商工具导出。

host_tools：电脑端BGM、网络字幕与原始媒体制备脚本。原始制备脚本可能含旧路径，使用前按实际素材与输出目录配置，不能直接对未知磁盘执行。

third_party/hmi_builder：BGM曲库GUI生成新触控页面所需的第三方Python工具，保留MIT许可证与来源README。当前六图HMI可直接打开；自动生成的新HMI只做离线结构检查，仍需厂商编译及实屏验证。

media：当前六张非压缩24位BMP和触控预览，不包含商业歌曲或视频原片。可使用自有授权素材通过相同方法生成PCM/RVA。

evidence：当前布线资源、时序及发布状态。release_reference为对应A/B参考位流，不代表重新构建已通过。

## 离线构建

需要合法安装的安路TD 6.2.1及对应器件库。用Python运行`build_portable.py image_A --td-home <TD安装目录>`，默认只在新目录生成构建脚本；加`--run`才执行离线构建。video_B同理。入口不访问下载线、不写Flash、不写TF。

原始视频工程部分PRJ属性含未转义的&，归档保留原文作为来源证据；便携入口仅在新构建副本修正XML转义。源码路径引用已经检查，未在本次资料整理中重跑完整综合布线。original_flow仅供溯源，其原始路径与种子不应直接当作最新六图独立构建入口。

视频目录原始副本缺少四个被PRJ引用的IPC元数据文件，本归档从同器件图片工程共享配置补齐PLL、TEMAC_CORE、pll_gen、rx_pll的IPC，使工程引用闭合；未改变视频HDL或生成过新的参考位流。补齐后仍需用TD检查生成IP与视频实例参数的对应关系。

## 媒体和模式

图片扫描限定物理扇区0至131071，按发现顺序最多六图。BGM为FAT32根目录连续BGM.LIB，不是任意MP4直接解码。视频源PCM每帧1714样本，帧率约24000/1714。图片与视频通过Flash双镜像重新配置，不是单个位流即时切换。
